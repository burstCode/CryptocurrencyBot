# CryptocurrencyBot

Telegram-бот на aiogram: курсы Bitcoin, Ethereum и Litecoin в USD, EUR и RUB из CoinGecko.

## Локальный запуск

Проверено на Python 3.14. Для работы нужны токен Telegram-бота от @BotFather и Demo API key CoinGecko.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
cp .env.dist .env
```

Заполните `TOKEN` и `COINGECKO_API_KEY` в `.env`. `CHAT_ID` можно оставить пустым. Файл загружается из каталога проекта.

```bash
python bot.py
```

Откройте своего бота в Telegram и отправьте `/start`, затем `/cryptocurrency_rate`.

## Команды и рассылка

- `/start` – приветствие.
- `/about` – описание.
- `/coins` – каталог CoinGecko по 10 монет на страницу; `/coins 2` – следующая страница.
- `/coins solana` – поиск по ID, названию или тикеру; `/coins solana 2` – страница результатов.
- `/rate solana` – курс одной монеты по точному CoinGecko ID в USD, EUR и RUB. Тикеры могут совпадать у разных монет, поэтому ID выбирается из `/coins`.
- `/chat_id` – ID текущего чата.
- `/cryptocurrency_rate` – котировки и изменение с последней успешной отправки в этот чат.

Чтобы настроить рассылку сначала начните диалог с ботом, получите `/chat_id`, укажите его в `CHAT_ID` и перезапустите бота. Для группы добавьте туда бота и вызовите `/chat_id` в группе. Часовая рассылка работает в один настроенный чат, в начале каждого часа по Москве. Первая отправка – в начале следующего часа.

Каталог `/coins/list` кешируется в памяти на час. `/rate` использует `/simple/price` и не меняет историю сравнения или состав часовой рассылки. Очень маленькие цены показываются с десятью значащими цифрами. API может не возвращать котировку для отдельных монет.

Документация: https://docs.coingecko.com/demo/reference/endpoint-overview

## Управление интервалом

В `.env` добавьте:

```dotenv
ADMIN_IDS=123456789,987654321
BROADCAST_INTERVAL_MINUTES=60
```

`ADMIN_IDS` – ID пользователей Telegram, которым разрешено менять интервал. Свой ID можно узнать командой `/my_id`. При пустом списке менять интервал через Telegram не сможет никто. Настройка прав требует перезапуска бота.

`/interval` показывает текущий интервал всем пользователям. `/interval 30` меняет его на 30 минут только для администратора. Допустимый диапазон – от 1 до 10080 минут (7 дней).

Изменение сразу перезапускает отсчёт и сохраняется в `broadcast_settings.json` рядом с кодом. Сохранённое значение имеет приоритет над `BROADCAST_INTERVAL_MINUTES`.
